SmartArray: Chainable Arrays with XSS-Safe Output
==========================================================================================
SmartArray wraps PHP arrays (usually database rows) in chainable collection methods, with
an HTML mode where fields encode themselves on output.

Access Cheat Sheet
-------------------
$row->name                  Read a field (interpolates in strings: "Hi $row->name")
$row->{'users.id'}          Braces for keys property syntax can't type (dots, dashes, numeric)
$row->name = 'Jean'         Write a field (same brace rule)
$row->phone ?? '(none)'     Fallback for missing keys and stored NULLs (never warns)
"{$user->bio->textOnly()}"  Chain any SmartString method on fields in HTML mode
                            (curly braces required for method calls inside strings)

Modes: SmartArrayHtml fields return self-encoding SmartStrings (for web pages); SmartArray
fields return plain PHP values (for JSON, CSV, email, CLI). Same methods in both; type-hint
SmartArrayBase to accept either. Missing data renders blank: empty results chain silently,
and a missing column on a result-set row warns with the key and your file:line.

Creation & Conversion
----------------------
Move between modes and plain arrays. The original values are always preserved.

SmartArrayHtml::new($array)      Create an HTML-mode collection; nested arrays become rows
SmartArray::new($array)          Create a raw-mode collection
->asHtml()                       This collection in HTML mode (same object if already HTML)
->asRaw()                        This collection in raw mode (same object if already raw)
->toArray()                      Plain nested PHP array with the original values
SmartArray::getRawValue($value)  Original value from any Smart object; plain values pass through unchanged

Single Elements
----------------
Return one element: a row as a collection, a value as a field. Silently blank when
there's nothing there (empty collection, out-of-range position).

->first()                Get the first element
->last()                 Get the last element
->at(index)              Get element by position, ignoring keys (0 is first, -1 is last)

Collection Checks
------------------
Return plain values, typically used in if statements.

->count()                Number of elements
->isEmpty()              True if there are no elements
->isNotEmpty()           True if there are any elements
->contains(value)        True if any element matches value (loose ==, "5" matches 5)

Row Position
-------------
Rows inside a result set know where they sit; use for separators and loop layout.

->isFirst()              True for the first row
->isLast()               True for the last row
->position()             The row's position, counting from 1

Filtering & Sorting
--------------------
Return a new collection; the original is never modified.

->where(field, value)         Keep rows where field matches value (loose ==, '1' matches 1)
->where(field)                Keep rows where field has a truthy value, i.e. not PHP empty()
->whereNot(field, value)      Drop rows where field matches value (inverse of where)
->whereNot(field)             Keep rows where field is PHP empty(): NULL, false, 0, "0", "", or missing
->whereInList(field, value)   Keep rows where tab-delimited field contains value (CMS Builder checkboxes)
->filter(callback)            Keep elements where callback returns true (callback gets raw values);
                              with no callback, removes falsy values ("", 0, NULL, false)
->sort(flags)                 Sort a flat list by value, renumbering keys
->sortBy(field, flags)        Sort rows by field; SORT_NATURAL sorts numbers the way people read them
->unique()                    Remove duplicate values from a flat list, keeping the first of each

Transforming & Grouping
------------------------
Return a new collection, except implode(), which returns a string (a SmartString in
HTML mode, so it still encodes on output).

->column(column)            One field from every row, like array_column($rows, 'name')
->column(column, indexKey)  Field values keyed by another field, like array_column($rows, 'name', 'id')
->column(null, indexKey)    Whole rows keyed by a field, like array_column($rows, null, 'id')
->columnAt(index)           The column at a position from each row, ignoring names (0 first, -1 last)
->indexBy(field)            Whole rows keyed by field (duplicate keys keep the last row)
->groupBy(field)            Rows grouped by field: one collection of rows per distinct value
->keys()                    The keys as a collection
->values()                  The values, with keys renumbered from 0
->map(callback)             Rebuild each element from what callback returns (callback gets raw values)
->merge(...$arrays)         Append arrays: numeric keys renumber, string keys overwrite
->implode(separator)        Join values into one string with separator between them

Requiring Results
------------------
Stop the page when the collection is empty (no matching record); otherwise return it
unchanged, so they chain inline. Text is HTML-encoded automatically.

->or404(text)            Send a 404 page and stop (default: "The requested URL was not found...")
->orDie(text)            Print text and stop
->orThrow(text)          Throw a RuntimeException with text
->orRedirect(url)        Send a 302 redirect and stop

Database Metadata
------------------
For collections created from query results; ZenDB and CMS Builder set these up automatically.

->mysqli()               All query metadata as an array
->mysqli(key)            One value by name (affected_rows, insert_id, query, ...)
->load(field)            Load related records for field using the configured load handler

Debugging
----------
->debug()                Show contents, current mode, and query metadata
->help()                 Display this help text
print_r($obj)            Shows just the element data; the class name tells you the mode

Working with single values? Fields in HTML mode are SmartStrings with their own methods
(or(), dateFormat(), numberFormat(), textOnly(), ...) and their own help: SmartString::help()

Full documentation: https://github.com/interactivetools-com/SmartArray
